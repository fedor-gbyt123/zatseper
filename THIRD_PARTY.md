# Сторонние компоненты

| Компонент | Где используется | Лицензия |
|---|---|---|
| [Godot Engine](https://godotengine.org) 4.7.2 | движок, входит в сборки | MIT |
| [Manrope](https://github.com/googlefonts/manrope), Copyright 2018 The Manrope Project Authors | шрифт интерфейса | SIL Open Font License 1.1 |
| [webrtc-native](https://github.com/godotengine/webrtc-native) 1.2.2 | онлайн через интернет | MIT |
| [libdatachannel](https://github.com/paullouisageneau/libdatachannel), [libjuice](https://github.com/paullouisageneau/libjuice) | внутри webrtc-native | MPL 2.0 |
| [usrsctp](https://github.com/sctplab/usrsctp) | внутри webrtc-native | BSD 3-Clause |
| [libSRTP](https://github.com/cisco/libsrtp) | внутри webrtc-native | BSD 3-Clause |
| [Mbed TLS](https://github.com/Mbed-TLS/mbedtls) | внутри webrtc-native | Apache 2.0 |
| [plog](https://github.com/SergiusTheBest/plog) | внутри webrtc-native | MIT |

Тексты лицензий webrtc-native, его библиотек и шрифта лежат в папке [licenses](licenses). Сторонние компоненты самого Godot перечислены в его [списке лицензий](https://godotengine.org/license/).

Онлайн использует бесплатный общедоступный сервис [ntfy.sh](https://ntfy.sh), чтобы игроки нашли друг друга, и публичные STUN-серверы Google. Сама игра идёт напрямую между игроками.
